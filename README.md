# a-b-c_folders_modern

... the phone keypad as a filing system – free A-B-C folders, sorted the way everyone already knows by heart.

The `ABC_Folders_modern.zip` file contains the folders

0-1 *(numbers and special characters)*

2-A-B-C

3-D-E-F

4-G-H-I

5-J-K-L

6-M-N-O

7-P-Q-R-S

8-T-U-V

9-W-X-Y-Z

The leading digit keeps the folders in keypad order. Looking for "O"? It's the 6 – no thinking required.

🪄 works magic for cloud files, bookmarks and url collections
